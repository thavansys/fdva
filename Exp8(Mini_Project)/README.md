# Amazon Sales & Customer Analytics Mini Project

## Deliverables
- Amazon_Analytics.ipynb — executed Python analysis
- amazon_sales_data.csv — project dataset
- Amazon_Analytics_PowerBI_Theme.json — Power BI theme
- PowerBI_DAX_Measures.txt — DAX measures
- PowerBI_Dashboard_Specification.md — Power BI dashboard blueprint
- Amazon_Analytics.twbx — Tableau packaged workbook
- Amazon_Analytics.twb — Tableau workbook source

## Power BI
A genuine `.pbix` file cannot be generated outside Power BI Desktop with these tools. The provided CSV, theme, DAX, and dashboard specification are ready to import into Power BI Desktop, after which use File > Save As > Amazon_Analytics.pbix.

## Dataset
The dataset is synthetic and designed for an academic analytics project. Do not describe it as official Amazon internal data.
