# FDVA – Fundamentals of Data Visualization and Analytics

This repository contains the practical experiments and mini project completed as part of the **Fundamentals of Data Visualization and Analytics (FDVA)** course.

The repository includes practical implementations using **Jupyter Notebook** for data analysis, visualization, and analytics.

## 📂 Repository Structure

```text

├── Exp 1/

├── Exp 3/
├── Exp 4/

├── Exp 7/
│
└── Exp8(Mini_Project)/
```

### 🧪 Experiments

The `Exp 1` to `Exp 7` folders contain the practical experiments performed as part of the FDVA laboratory.

Each experiment contains the corresponding **Jupyter Notebook implementation** and required practical work.

### 📊 Mini Project

The `Exp8(Mini_Project)` folder contains the FDVA mini project.

### Amazon Sales Analytics

The mini project focuses on analyzing **Amazon sales data** and presenting meaningful insights using data analytics and visualization techniques.

The project includes:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales analysis
- Product and category analysis
- Customer analysis
- Regional analysis
- Order-status analysis
- Data visualization using Python
- Interactive dashboard development using Power BI
- Interactive dashboard development using Tableau

## 🛠️ Technologies Used

- **Python**
- **Jupyter Notebook**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Power BI**
- **Tableau**

## 📈 Project Objectives

The main objectives of the mini project are:

1. Clean and preprocess Amazon sales data.
2. Analyze sales and order-related patterns.
3. Identify important product and category trends.
4. Analyze customer and regional purchasing patterns.
5. Visualize important insights using Python.
6. Develop interactive dashboards using Power BI and Tableau.
7. Present the results in an easy-to-understand visual format.

## 📊 Dashboard Tools

### Power BI

Power BI is used to create interactive dashboards for exploring:

- Sales performance
- Profit and revenue
- Product categories
- Customer segments
- Regional performance
- Order status
- Key performance indicators (KPIs)

### Tableau

Tableau is used to create interactive visualizations for analyzing Amazon sales data and identifying patterns across different dimensions such as categories, regions, order status, quantity, and time.

## 💻 How to Run the Jupyter Notebooks

### 1. Clone the repository

```bash
git clone https://github.com/thavansys/fdva.git
```

### 2. Navigate to the repository

```bash
cd fdva
```

### 3. Install the required Python libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open the required experiment folder and run the notebook cells sequentially.
